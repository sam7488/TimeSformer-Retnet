# TimeSformer-RetNet Research Project

This repository contains experiments investigating the replacement of TimeSformer encoder blocks with RetNet-based retention mechanisms to improve computational efficiency in video classification tasks.

## Experiments

- Dataset A: TimeSformer Baseline
- Dataset A: RetNet Variant
- Dataset B: TimeSformer Baseline
- Dataset B: RetNet Variant

## Objectives

- Reduce computational complexity
- Reduce memory consumption
- Maintain competitive classification accuracy

## Repository Structure

- notebooks/: training and evaluation notebooks
- figures/: architecture and result visualizations
- results/: experiment outputs and metrics
- docs/: publication materials
